## TasksMax=256 的实现

- `policy.sh`：新增只读常量 `BR_TASKS_CHROME=256`（`BR_TASKS=32` 不变）。
- `host.sh`：仅当 prefix 为 `e2-chrome-batch` 时申请 `TasksMax=$BR_TASKS_CHROME`。
- `envelope.sh`：unit 名匹配 `e2-chrome-batch-*` 时期望 `pids.max=$BR_TASKS_CHROME`，否则 `BR_TASKS`。
- 不存在环境变量覆盖通道：payload 无法自行抬高配额，envelope 的防篡改校验仍然有效。
